Exam Score Regression (Python)

This project uses Python to analyse exam score data and build a regression model.

It includes:

Loading and inspecting the dataset

Basic data exploration to understand input features and exam scores

Preparing features and target variables

Training a regression model

Evaluating predictions against actual scores

Tools used:

Python

pandas

scikit-learn

matplotlib

The notebook is written to reflect a basic end-to-end regression workflow commonly used in data analysis.
